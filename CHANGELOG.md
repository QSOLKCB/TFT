# Changelog

All notable changes to TFT Lab are documented here. This project follows
[Semantic Versioning](https://semver.org/) while it remains an alpha research
prototype.

## [Unreleased]

## [0.2.0] - 2026-07-17

### Added

- Installable `qsol-tft` Python package metadata and `tft` console entry point.
- Reproducible experiment, artifact, and verification workflow.
- Python 3.10–3.13 continuous integration with NumPy 1.26 compatibility
  coverage.
- Project citation, contribution, security, and release metadata.

### Changed

- Reframed the repository as **TFT Lab**, an alpha-status numerical research
  prototype with an explicit scientific claim boundary.
- Separated NumPy core requirements from optional visualization and development
  dependencies.

### Fixed

- NumPy 2.x compatibility in the demonstration workflow.
- Sample-rate propagation, numerical input validation, and deterministic output
  handling.
- Inconsistent licensing, version, and repository metadata.
